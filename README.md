# News Explorer

News Explorer provides a clean and easy to use resource for surfing the news.

## Functionality

You type a topic you're interested in into the search bar and you receive a list of cards with information about the topic you searched.

## Technologies Used

Frontend Framework & Libraries:

- React (with Hooks: useState, useContext, useEffect, useRef)
- React Router DOM (for routing and navigation)

Web Technologies:

- HTML5 (semantic elements, forms)
- CSS3 (custom properties, flexbox/grid layouts)
- JSX (React's syntax extension)

Development Tools:

- Node.js and npm (package management)
- Git (version control)

Miscellaneous:

- Custom scrollbar
- Responsive design (desktop, tablet, and phone)
- Accessibility features (semantic HTML and form handling)

This is a modern React application that demonstrates proficiency with current web development technologies and best practices!
